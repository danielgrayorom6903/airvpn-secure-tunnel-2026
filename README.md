## Overview

AirVPN gives Windows users a more configurable way to manage VPN connections, combining encrypted tunneling with controls for routing, protocols, and connection behavior. Its design is aimed at structured traffic handling and privacy-aware network use.

The application brings together functions such as split tunneling, a kill switch, and DNS leak protection. It is also suited to cross-platform-oriented workflows, multilingual use, and network setups that require adjustable configuration options.

---

## Key Capabilities

- Creates encrypted VPN tunnels for privacy-focused traffic routing
- Works with OpenVPN, WireGuard, and IKEv2
- Lets users direct selected applications or routes through split tunneling
- Can block traffic when the VPN tunnel is interrupted through kill switch behavior
- Helps limit DNS lookup exposure with DNS leak protection
- Provides protocol obfuscation for adaptable network traversal
- Includes no-log policy support within the service profile
- Offers server optimization to assist with server selection and connection performance
